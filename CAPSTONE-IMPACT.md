# Capstone Impact Project: Workflow & Next Case Study

## 1. How to Add the Next Case Study (3-Beat Workflow)
Every future case study will follow the structured 3-beat narrative shape to maintain consistency and high impact:
1. **The Problem:** Clearly state the background, pain point, or operational bottleneck faced before the solution.
2. **What I Did:** Outline the technical architecture, AI tools, frontend workflows, and exact implementation steps executed.
3. **What Came of It (The Impact):** Quantify results with tangible metrics, user feedback, or speed improvements.

### Step-by-Step Publishing Process:
1. Open the primary **Claude Project** containing the portfolio system instructions, context, and UI design kit.
2. Prompt Claude with the raw notes from the new project to generate a clean, responsive HTML card snippet using the 3-beat structure.
3. Paste the generated card component directly into the `#projects` grid section inside `index.html`.
4. Commit and push changes via Git (`git add . && git commit -m "Add new case study" && git push origin main`) for automatic deployment on Vercel.
